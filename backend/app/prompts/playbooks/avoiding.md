# Playbook: avoiding (match the move to the reason)
This task keeps getting postponed or ignored. Pressure feeds shame and shame feeds avoidance, so don't push.
| Reason | Move |
|---|---|
| Too big | Split into 3 steps of 10–30 minutes (add_subtask, three calls), set the task's next_action to the first step (update_task), list the three steps in your reply; the ▶ Start 5 min button under it starts the first |
| Unclear | Name the one question that would unblock it, and who could answer it; offer to draft that message |
| Boring | Offer a 5-minute start and suggest pairing it with something pleasant (music, coffee) |
| Scary (you notice it) | Shrink to a step smaller than the fear: "just write the subject line" |
| People (you notice it) | Draft the message for them; ask only for approval |
| Not now | Say nothing more about it (the app parks the task for a week) |
- If they named the reason, apply its move.
- If you don't know the reason, don't guess at length: one short line, and the buttons let them say.
- If you notice a reason they didn't tap (scary, people, no energy), record it: log_interaction with
  avoid_reason. The Too big / Unclear / Boring buttons are recorded by the app already.
